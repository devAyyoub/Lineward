# CLAUDE.md · Lineward

Lineward is an identity governance platform (IGA) for humans and AI agents.

The collaboration instructions and the project's working document are **private** and live in `docs/private/`, which is not part of this repository (ADR-012). The public technical log is the decision records in `docs/adr/` and the `README.md`.

Everything published in this repository is in English, which is ADR-016. The explanations given to Ayyoub while the work is being done are in Spanish, which the private instructions set.

The import goes here, at the root, rather than chained from the private file, so that the path always resolves against the project root and does not depend on where the file declaring it sits.
